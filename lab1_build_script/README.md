# Практическая работа 1. Скрипт для сборки

Скрипт `build.sh` (POSIX Shell) собирает исходный файл на C, C++ или TeX.
Имя конечного файла берётся из комментария `Output:` внутри исходного файла.

## Использование
```sh
./build.sh examples/hello.c     # -> examples/hello_c
./build.sh examples/hello.cpp   # -> examples/hello_cpp
./build.sh examples/doc.tex     # -> examples/document.pdf
echo $?                         # код возврата
```

## Коды возврата
| Код | Значение |
|-----|----------|
| 0 | успешная сборка |
| 1 | неверный вызов |
| 2 | файл не найден или недоступен |
| 3 | нет комментария `Output:` |
| 4 | неподдерживаемый тип файла |
| 5 | не удалось создать временный каталог |
| 6 | ошибка компиляции |
| 7 | не удалось записать результат |
| 128+N | прервано сигналом N |

## Как выполнены требования
1. Информативные коды ошибок — см. таблицу.
2. Комментарий `Output:` ищется утилитой `sed`.
3. Сборка выполняется во временном каталоге, созданном `mktemp -d`.
4. Каталог удаляется при любом завершении: `trap` на `EXIT`, `HUP`, `INT`, `QUIT`, `PIPE`, `TERM`. Промежуточные файлы (`.aux`, `.log`) остаются в нём и удаляются вместе с ним.
5. Конечный файл копируется рядом с исходным.
